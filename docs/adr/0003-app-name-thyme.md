# App name: Thyme

The app is named "Thyme" — a deliberate double meaning between thyme the herb (food, cooking) and "time" (expiry tracking, the core free-tier feature). The internal package name remains `com.golnaz.fridgelist` and does not need to change; only the display name and store listing use "Thyme".

An English name was chosen over a German one (e.g. "Frisch", "KühlCheck") because the product is built for international expansion from day one, even though v1 launches in Germany first. English app names are common and accepted in German app stores, and "Thyme" is instantly understood across European markets without translation.

**Considered options**: "Frisch" (too German-specific), "Salat" (too narrowly associated with salads), "Zest" (strong but no expiry double meaning), "FridgeList" (descriptive but generic and no personality).
